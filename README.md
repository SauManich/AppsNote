# Notapp's

## Descripción

Notapp's es una aplicación web sencilla para gestionar notas rápidas. Permite crear, buscar, filtrar y eliminar notas, clasificándolas por etiquetas como Trabajo, Personal, Ideas y Recordatorios. La interfaz es moderna y responsiva, utilizando HTML, CSS y JavaScript puro, y almacena las notas localmente en el navegador mediante `localStorage`.

## Estructura del Proyecto

- **index.html**  
  Contiene la estructura principal de la aplicación, incluyendo los formularios para agregar notas, los filtros, el listado de notas y los modales para confirmación de eliminación.

- **styles.css**  
  Define los estilos visuales de la aplicación, asegurando una experiencia atractiva y responsiva en diferentes dispositivos.

- **main.js**  
  Implementa la lógica de la aplicación: manejo de eventos, renderizado dinámico de notas, filtrado, búsqueda, almacenamiento y eliminación de notas.

## Funcionalidades

- **Agregar Nota:**  
  Haz clic en "Agregar" para abrir el formulario y crear una nueva nota con título, contenido y etiqueta.

- **Buscar y Filtrar:**  
  Usa la barra de búsqueda para encontrar notas por título o contenido. Filtra por etiqueta usando el menú desplegable.

- **Eliminar Nota:**  
  Cada nota tiene un botón de eliminar. Al hacer clic, se muestra un modal de confirmación antes de borrar la nota.

- **Persistencia Local:**  
  Las notas se guardan en el almacenamiento local del navegador, por lo que permanecen aunque recargues la página.

## Cómo usar

1. Abre `index.html` en tu navegador.
2. Agrega una nota usando el botón "Agregar".
3. Busca o filtra notas según tus necesidades.
4. Elimina notas si ya no las necesitas.
